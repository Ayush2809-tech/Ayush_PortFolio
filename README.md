# Ayush Saxena — Developer Portfolio 🚀

> **B.Tech CSE (AI & ML) | Python & Django Developer**

An interactive, responsive **3D Glassmorphism Developer Portfolio** built using **HTML5, CSS3, JavaScript, Bootstrap 5.3, and Three.js**.

---

## 🌟 Features

- **3D WebGL Canvas (Three.js)**: Interactive particle constellation background with mouse parallax effects.
- **Glassmorphism Design**: Frosted glass cards with backdrop filters and dynamic neon radial glows.
- **Interactive Audio Engine**: Subtle cyber sound effects powered by the Web Audio API (with toggle switch).
- **Theme Accent Switcher**: Switch between Cyber Cyan, Neon Purple, and Matrix Emerald themes.
- **Role Rotator**: Dynamic typewriter effect highlighting core expertise.
- **Interactive Modals**:
  - **Resume Viewer**: ATS-compatible formatted resume with 1-click Print/PDF save.
  - **Project Architecture Inspector**: Detailed feature breakdown for showcased projects.
- **Filterable Showcase**: Filter projects by categories (Full Stack / Django, PostgreSQL & Cloud).
- **1-Click Copy**: Direct clipboard copy for email and phone with animated toast notifications.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3 (Vanilla Glassmorphism Design System), JavaScript (ES6+)
- **Framework**: Bootstrap 5.3
- **3D / Graphics**: Three.js
- **Icons**: Bootstrap Icons, FontAwesome 6
- **Typography**: Google Fonts (Outfit & JetBrains Mono)
